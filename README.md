# 실시간 자막 (LiveCaption)

유튜브 같은 다른 앱의 소리나 주변 소리를 **폰 안에서** 한국어로 인식해서, 화면 맨 위에 자막으로 띄워주는 안드로이드 앱입니다.

- 안드로이드 10 이상
- 인터넷 없이 폰 안에서 인식해요 (sherpa-onnx, 한국어 스트리밍 Zipformer 모델)
- 자막은 터치를 막지 않아서 아래 앱을 그대로 쓸 수 있어요
- 소리 종류는 두 가지예요: 폰에서 나오는 소리(유튜브 등) / 주변 소리(마이크)
- 글자 크기, 위치(위/가운데/아래), 배경 진하기, 줄 수를 고를 수 있어요. 자막이 켜진 상태에서 바꿔도 바로 적용돼요

## APK 받기
이 저장소의 **Releases**에서 `LiveCaption.apk`를 내려받아 설치하세요.
(코드를 바꿔서 `main` 브랜치에 올리면 GitHub Actions가 새 APK를 자동으로 만들어요.)

## 사용법
1. 앱을 열고 **① 다른 앱 위에 표시 권한 켜기**를 누른 뒤 허용하세요.
2. 소리 종류를 고르고 **② 자막 시작**을 누르세요.
3. 폰 소리 모드에서는 "화면 녹화/공유" 허용 창이 떠요. **전체 화면**을 고르고 시작을 누르세요. 화면은 녹화되지 않고 소리만 씁니다.
4. 유튜브를 열면 영상 위에 자막이 나와요.
5. 끌 때는 알림창의 **[끄기]**를 누르거나, 앱에서 **자막 끄기**를 누르세요.

## 구조
- `MainActivity.kt`: 설정 화면과 권한 요청
- `CaptionService.kt`: 소리 받기 → 인식 → 자막 창 표시 (포그라운드 서비스)
- `.github/workflows/build.yml`: 엔진(AAR)과 한국어 모델을 내려받아 APK를 빌드
